## tools/shaders/convert-shaderamp.py
- `RISK` tools/shaders/convert-shaderamp.py:196-200,208,226 — only `Skip` and `FileNotFoundError` are caught per shader. A `customUniforms` entry without `name` (KeyError, :200), a non-numeric/None `default` (`float()` at :96 → ValueError/TypeError), a buffer without `shaderName` (:208), or a meta that is not a JSON object aborts the whole run with a traceback and no `_report.json`, losing the conversion of every shader before it. Fix: catch `Exception` per shader and record `reason: f'error: {e}'`.
- `RISK` tools/shaders/convert-shaderamp.py:98 — the uniform regex only matches `uniform <type> <name>;`. `uniform float gain, speed;` and `uniform highp float k;` are left in the source untouched (checked with a pure-regex repro: only the single-declarator lines are rewritten), so custom float uniforms declared that way keep their uniform form with no value bound (reads 0) instead of becoming the `const float` with the ShaderAmp default, or being skipped as "unsupported uniform". The validator only catches compile errors, so such a shader is imported with silently wrong behaviour. Fix: handle precision qualifiers and comma lists, or `Skip` when any `uniform` remains after substitution.
- `QUALITY` tools/shaders/convert-shaderamp.py:24-26,182,201,208,222,229 — module-level script with no `__main__` guard or usage message (`sys.argv[1]` → IndexError), and every `open()` is left to garbage collection.
