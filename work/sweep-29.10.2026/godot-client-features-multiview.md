## godot/client/features/multiview/mv_layout.gd
- `RISK` godot/client/features/multiview/mv_layout.gd:70-81 — the DeckLink row of `default_layout` is almost unreachable and wrong when reached. PGM/PRV bands already fill the canvas (last band `h = ch - y`), so `bottom_h = ch - active*floor(ch/active)` is < `active` and never ≥ 40 for any real screen count; the row exists only when `active == 0` (no PGM/PRV channels).
