- `QUALITY` src/app-context.js:55-58, 36-44 — `ctx.CHOICES_MEDIAFILES` is a getter that runs `state.getState()` on every access. `getState()` JSON-clones channels, media, templates, osc and audio (`src/state/state-manager.js:426-439`), and only then maps `media`. `state.getStateShared()` (`state-manager.js:414`) exists for exactly this read-only case (WO-401 F6). The getter is read per clip resolve (`src/media/caspar-cls-id.js:75`, `src/caspar/amcp-clip-resolve.js:71`) and per cinf cycle (`src/utils/query-cycle.js:175,225`). With this box's 409 media entries a media+channels+templates clone costs about 0.6 ms (measured with `JSON.parse(JSON.stringify())` over the live `/api/state` payload); with OSC and audio data it is larger (WO-401 measured 43–49 ms for the full clone). Fix: read `state.getStateShared().media`. The same applies to `catalogTemplatesFromState`.
- `QUALITY` src/app-context.js:101-113 — `sealAppContextBootFields` makes `config`, `state`, `persistence` and `configManager` non-writable. In strict mode any `ctx.config = x` (including a test harness that builds a ctx by hand) throws a TypeError, while `Object.assign(ctx, …)` in sloppy code would fail silently. `src/utils/handlers.js:55` already guards the getter-only `CHOICES_TEMPLATES` for this reason. The getters `CHOICES_MEDIAFILES` / `CHOICES_TEMPLATES` also have no setter. Intentional (WO-100), but the contract is only in the code.
