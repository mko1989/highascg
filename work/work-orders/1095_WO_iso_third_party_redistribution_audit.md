# WO-1095 — ISO redistribution audit: what an ISO built today would ship that we have no right to distribute

**Area:** os-iso, process
**Status: OPEN**

Owner rule (16.11): *"we cant bake anything into iso that i have no right to distribute"*.

This WO is a read-only audit. It changes no code, config or exclude lists and builds nothing. It ends in a ranked
fix list, the obligations, the owner decisions and a gate design. The fixes are the follow-up WOs listed at the end.
Person detection (Ultralytics YOLO26 AGPL weights, ONNX exports, venv under `~/.local/share/highascg`) is **handled by
WO-1094** and was not investigated here.

## Method

1. **What eggs reads.** penguins-eggs 26.10 (`eggs remaster --clone`) reads only
   `/etc/penguins-eggs.d/custom.exclude.list`. That file is generated by
   `tools/eggs/live-usb/generate-eggs-config.js exclude --embed 1` from four fragments: stock-custom, old-template,
   highascg-embed-server and decklink. I regenerated it into the scratchpad (`today.exclude.list`). It equals the
   installed list (11.11) plus the WO-1076 `modules` lines.
   - mksquashfs `-wildcards -ef` semantics apply: anchored, per-component fnmatch, and a matched directory drops its
     whole subtree.
   - The merged-usr check (WO-430): a `lib/…` line matches nothing, so it needs a `usr/lib/…` twin.
   - coa's built-in clone excludes cover dev, proc, sys, run, tmp, mnt, media, `etc/fstab`, machine-id, ssh host keys,
     NM `system-connections`, `var/log/*`, `home/*/.cache/*`, shell histories, trash and `boot/efi/EFI`. They do
     **not** cover `root/*`.
2. **What the last ISO shipped.** I listed the squashfs of the newest ISO,
   `/home/eggs/highascg-nvidia-615-2026-11-11_1249.iso` (squashfs at LBA 9314, `unsquashfs -lls -o`): 190,017
   entries. That list is the evidence for "shipped" below.
   - "Would ship today" means present on the box now and matched by no exclude line and no reset step.
3. **Reset steps that also keep things out** (`build-highascg-egg.sh`):
   - `reset-iso-operator-config.sh` runs with PART=stick (l.155) and again with PART=tree after preflight (l.191,
     WO-935).
   - `write-iso-default-config.js` `resetProjectsDir` deletes every project JSON and rm -rf's every other entry under
     `projects/` (l.106–126), so `_gdtf`, `_mvr` and `_trash` are gone.
   - The config slices are factory-reset. The device identity is set aside during produce (63bfee86).
   - `install-iso-defaults.sh` runs `npm prune --omit=dev --omit=optional`.
4. **Licences** were read from these sources, with the decisive sentence quoted in each row:
   - `/usr/share/doc/<pkg>/copyright`;
   - the vendor EULA on disk;
   - the NDI SDK licence PDF (decoded from its streams, because poppler is not installed);
   - file headers;
   - npm `package.json` files;
   - upstream web pages (WebFetch), with the URL noted.
5. **Secrets.** I scanned small shipping files for key and token patterns (PEM private keys, tskey, ghp/github_pat,
   sk-ant, AKIA, Slack). I grepped config key names only and printed no value.

## Ranked: would ship today, must not — with the smallest fix

Ranked by legal exposure × ease of exploitation. Exclude lines are mksquashfs `-ef` globs; each needs its `usr/` twin
where the path starts with `lib/` (none below do), plus a verifier needle.

1. **Mario Nintendo sprites + sounds** (`template/mario/sprites`, `sounds`). These are a third party's famous IP,
   shipped in the ISO, the public repo and the release tarballs. An ISO exclude does not fix the repo or the releases.
   *Fix:* remove the assets, or replace them with CC0 art and sounds; keep the MIT engine code. `git rm` is done in
   the follow-up WO, not here.
2. **Shader library, 155 NC + 28 unknown** (`template/shaders`). It is in the repo, ISO and releases, and is used
   commercially on paid shows.
   *Fix:* ship only the permissive ones. Move the NC and unknown ones to an opt-in per-box download that does not go
   into the repo or ISO, or drop them. Add a header licence check to the gate.
3. **`wetransfert` npm package** (no licence). It is in the ISO node_modules and the release tarballs.
   *Fix:* replace it with own code for the WeTransfer download (`src/api/routes-ingest.js:115`), or a licensed
   package; then remove it from `package.json`.
4. **GDTF Share credentials** (`home/casparcg/.highascg/gdtf-share.json`). The T&C §5 breach is on every ISO.
   *Fix:* exclude line `home/casparcg/.highascg/gdtf-share.json` plus a needle; the operator logs in per box.
   Supersedes the 22.10 decision.
5. **Client data:** `~/Documents/*.csv` and `~/highascg-backups/`.
   *Fix:* `home/casparcg/Documents`, `home/casparcg/Documents/*`, `home/casparcg/highascg-backups` and
   `home/casparcg/highascg-backups/*` (the Documents pair replaces the MagicQ-only lines).
6. **Shutter Encoder** (`/opt/shutter-encoder`; bundled models of unknown licence; GPL ffmpeg with no offer).
   *Fix:* `opt/shutter-encoder`, `opt/shutter-encoder/*`, its `usr/share/applications`/pixmaps entries and
   `var/lib/dpkg/info/shutter-encoder*`. Or uninstall it from the build host (owner).
7. **BMD leftovers.**
   *Fix:* `usr/share/icons/hicolor/*/apps/BlackmagicDesktopVideoSetup.png`,
   `usr/share/icons/hicolor/*/apps/DesktopVideoUpdater.png`, `etc/blackmagic`, `etc/blackmagic/*`,

   *Fix:* `usr/share/applications/magic*.desktop`, `usr/share/pixmaps/magic*.png`,

## Gate design (design only; to be implemented in a follow-up)

**Manifest.** `tools/eggs/live-usb/third-party-payload.json` (repo-tracked, reviewed like code). Each entry has:

```
{ "id": "caspar", "globs": ["home/casparcg/highascg/bin/casparcg"], "licence": "GPL-3.0",
  "notice": "usr/share/doc/highascg/licenses/third-party/casparcg/LICENSE",
  "source": "https://github.com/mko1989/casparcg-server/tree/highascg-{sha}", "verdict": "ok-conditions" }
```

- **dpkg classes:** packages are allowed by name, and the origin component must be `main`, `universe`, `restricted`
  or `multiverse` from the Ubuntu archive, or a listed PPA. Each multiverse or non-archive package needs its own
  entry.
- **Deny-lists:**
  - vendor names: blackmagic, desktopvideo, magicq, chamsys, zoom, nomachine/NX, shutter-encoder, unrar/Rar.so;
  - secret-name patterns: `*credential*`, `*password*`, `*.pem`, `*_key`, `known_hosts*`, `*history`, `cookie`,
    `seen-bssids`, `gdtf-share.json`, `*.bak.*`.

**Verifier step.** After produce, extending `verify-iso-squashfs-excludes.sh` or adding a new JS verifier it calls:

1. List the squashfs (`unsquashfs -lls -o <offset>`).
2. Subtract the files that `dpkg -L` attributes to allowed packages, where the package comes from the *squashfs's*
   own `var/lib/dpkg`, not the host's, which catches the WO-431 phantom entries.
3. Subtract the manifest globs.
4. **Fail the build** on:
   - any leftover outside `home/casparcg/highascg/{src,client,godot,tools,docs,config,projects,...}`;
   - any deny-list hit;
   - any `template/**` file whose header carries "NonCommercial", "BY-NC" or "All rights reserved" (or has no licence
     line, for shaders);
   - any npm production dependency (from the shipped `node_modules/*/package.json`) whose `license` is not on the
     SPDX allowlist (MIT, BSD-*, ISC, Apache-2.0, 0BSD, CC0, or dual including one of these);
   - any manifest entry whose `notice` file is missing from the image;
   - a non-empty `privateKeyPem`, or any PEM private key anywhere.
5. Print one line per failure with the path and the manifest id.

**Pre-build dry check.** The same matcher runs on the live host against the generated exclude list (scan `/` with
the `-ef` semantics, including the merged-usr check). The build fails fast before produce, and the owner can run it at
any time. Add both to the curated smokes, with a fixture squashfs listing as input.
