## 1. Investigation findings (2026-07-13)

### Exclusion mechanism (single squashfs mechanism, several sources)

`eggs produce --clone --excludes static` reads `/etc/penguins-eggs.d/exclude.list`, which HighAsCG builds at prepare-time by merging repo fragments (`merge-penguins-eggs-exclude-highascg.sh`, called from `prepare-eggs-clone-with-exfat.sh:149-159`):
- `tools/eggs/live-usb/exclude.list` — upstream template + a **stale baked-in HighAsCG block (lines 105-204)** duplicating the fragments (drift risk documented in `EGGS_EXCLUDE_LIST.md:140-142`; it already lacks newer entries).
- `penguins-eggs-exclude-highascg-embed-server.list` (default, `HIGHASCG_ISO_EMBED_SERVER=1`) / `penguins-eggs-exclude-highascg-fragment.list` (WO-47 exFAT mode) / `penguins-eggs-exclude-decklink.list` (always).
- Post-build assertions: `verify-iso-squashfs-excludes.sh` (wired at `build-highascg-egg.sh:139-140`) — **never checks `.private/`, `projects/_trash/`, `config/*.bak*`**.
- Factory reset before produce (`build-highascg-egg.sh:88-89` → `reset-iso-operator-config.sh` → `write-iso-default-config.js`): wipes `config/*.json` outside `PRESERVE_JSON`, regenerates modular config from `src/config/defaults.js` + `factory-starter.js`, resets `projects/` to one starter project — **but only handles top-level `*.json` + `_autosave`**.

### Confirmed leaks (ship in the ISO today)

1. **`~/.private/highascg7579/`** — replication `pairing.json`, `tailscale/status.json`, `syncthing/device-id.txt` + `folders.json`. **Device identity/auth material; zero exclude/reset/verify coverage.** Every produced ISO/clone carries this box's identity.
2. `config/casparcg.config.bak.*` (9) + `casparcg copy.config` — not `.json`, so the reset skips them; no exclude either.
3. `projects/_trash/*` (34 tombstone dirs, 780 KB) — reset has no `_trash` branch.
4. `_media/` LevelDB scanner cache (1.7 MB) — unaccounted anywhere (decide: exclude or document).
5. Root build-host stamps (`.applied-at`, `.applied-stamp`, `.highascg-build-stamp`, `BUILD_STAMP`) — could make a fresh box think build-host steps already ran (low severity, decide).
6. Working-tree clutter (doesn't ship, but noise): 40 throwaway `projects/*.json` + 39 autosaves + 11 sync-conflict files (wiped by reset pre-produce; cleanup separately owner-gated).

### Defaults concept — already half-built

`src/config/factory-starter.js` is the single source of truth for the starter project + factory modular config (reused by runtime "New Project" via `src/engine/new-project.js` and by the eggs reset via `tools/eggs/live-usb/starter-project.js`). What's missing: `_trash`/non-JSON coverage in the reset, an exported manifest shared by reset + verify, and verify assertions.
