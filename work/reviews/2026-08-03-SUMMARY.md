**Exposure multiplier for everything in src-api:** this box runs `enforceAuth: false`,
`exposeToNetwork: true`, empty `apiToken`, bound `0.0.0.0:4200`; `GET /api/state` answers
unauthenticated. Every API finding is reachable from the LAN/tailnet. Turning on auth (or
binding to loopback + tailnet only) is the single cheapest risk reduction available.

## Themes

- **Boundary validation is inconsistent, not absent.** Media paths get `resolveSafe()`, shaders
  get `isValidShaderId()`, but project slugs get a bare `path.join` and AMCP encoder fields get
  `.trim().toLowerCase()` where they need a whitelist. The fixes are small and local.
- **`process.exit(1)` on uncaughtException turns any missing stream/spawn `'error'` handler into
  a full outage.** Five such sites found across two reviews.
- **One-way latches with silent failure** (client sync gate, `getChrome()` cache, replication
  standalone teardown) — each turns a transient fault into a permanent degraded state with no
  operator-visible signal.
- **Durability layer is the weakest subsystem.** exFAT sync ignores both the WO-161 atomic-write
  discipline and any staleness check; config load-error handling amplifies corruption.
- **Test rot outside the curated gate**: 10 files / 18 failing tests, `test:ci:full`
  permanently red (so never run), one test file that has never executed an assertion, and one
  that sets the production clock if run as root.
- **What is genuinely good:** XSS discipline in the client is consistent, AMCP/take contracts are
  documented where enforced, replication has real split-brain guards, atomic config writes are
  correct where used, ops tooling has `--yes`/`--dry-run` gates, arg-array spawning is near-universal.
