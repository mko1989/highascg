# WO-512: EVERY directory pattern here MUST be anchored with a leading '/'.
# An rsync pattern without a leading slash matches at ANY depth, so a bare `media/` also excluded
# `src/media/` (production code) and a bare `lib/` also excluded `scripts/lib/` — both shipped, both
# silently missing from every update for as long as this file has existed. The same mistake in the
# manual procedure (`--exclude 'config/'`, which also matched `src/config/`) took the box down: a new
# `src/api/` file landed while the `src/config/` module it required did not.
#
# Two deliberate exceptions below keep their any-depth behaviour: `node_modules/` and `.git/`.
